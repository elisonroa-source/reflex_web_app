# 🍳 Proyecto Web de Cocina Interactiva con Reflex

## 📌 Descripción

Este proyecto es una aplicación web desarrollada con el framework **Reflex** utilizando Python y Poetry.

La página simula una interfaz de cocina interactiva donde el usuario puede presionar botones para cambiar el contenido de la pantalla y ver una imagen relacionada con la cocina.

El objetivo del proyecto es aprender el desarrollo web con Python usando Reflex, además de practicar el uso de Git, GitHub y entornos virtuales con Poetry.

---

## ⚙️ Tecnologías utilizadas

- Python 3.12
- Reflex
- Poetry
- Git / GitHub

---

## 📥 Instalación del proyecto

### 1. Clonar el repositorio

git clone https://github.com/elisonroa-source/reflex_web_app.git

---

### 2. Entrar al proyecto

cd reflex_web_app

---

### 3. Instalar dependencias

poetry install --no-root

---

### 4. Activar entorno virtual

poetry shell

---

## 🚀 Ejecutar el proyecto

Para iniciar la aplicación web:

poetry run reflex run

Luego abrir en el navegador:

http://localhost:3000

---

## 🍳 Funcionalidades

- Página web de cocina interactiva  
- Botones que cambian el contenido:
  - Inicio  
  - Recetas  
  - Chef  
- Mensajes dinámicos en pantalla  
- Imagen de cocina integrada  
- Diseño con colores azul y rojo
